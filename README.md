# Sales-Analysis-By-Lean-Solutions-in-Excel
  
### Dataset Description  

This dashboard provides an overview of sales performance across multiple dimensions, including time, customers, products, and regions.  

### Key Metrics and Visualizations  

- **Total Sales**: Displays the overall sales value of 984,571.  
- **Top Customers**: Highlights the three highest contributing customers with their respective sales figures.  
- **Sales by Region**: A pie chart representing the percentage contribution of different regions to total sales.  
- **Sales by Product**: A ranked list of products based on their sales values.  
- **Monthly Performance (Target vs Actual)**: A bar and line chart comparing actual sales against targets for each month.  
- **Weekly Sales Trend**: A line chart tracking weekly sales fluctuations.  
- **Country-wise Sales Distribution**: A map visualization showing sales contributions from different countries.  

This dashboard is built in Excel, leveraging data visualization techniques to track and analyze sales performance effectively.
